# Agent 协作规划页

状态：已交付，待用户验收。

## 已确认范围

用户要求将「正在规划」页改为工作示意图，只关注 Agent 交互、当前阶段和哪位专家正在生成。Agent 之间使用虚线流动连接；点击专家才查看正在做什么、查询内容和结果。用户明确要求「帮我做一下优化。开始吧」，随后补充「高级感中又带着些许简约的设计，苹果风」。

采用浅色留白、细边框、低饱和图标、轻阴影与克制的流线动画。保留总规划师及现有七位专家，不增加外部服务或模型调用。

## 验收范围

- AW-01：主界面为阶段条和协作图，去掉默认展开的任务、查询、结果长列表。
- AW-02：状态来自已保存与实时事件，终止、完成、等待确认时停止运行效果。
- AW-03：每个节点支持键盘和点击，详情包含该专家实际工作、查询、结果、收发消息；关闭后返回原节点。
- AW-04：虚线表示既有工作流，真实协作消息另映射连线；未启动专家不表现为工作中。
- AW-05：覆盖方向准备、确认、并行研究、预算与路线、复核、最终交付。
- AW-06：桌面和手机可用，无页面横向溢出，支持减少动态效果偏好。
- AW-07：停止、重试、方案确认和完成后的协作回看继续可用。
