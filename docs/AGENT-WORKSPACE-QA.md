## 发现与复查

1. **最新协作消息可能选错（已修复）**。同一发送方向重复消息更新 Map 后仍保留旧插入位置，会影响页脚“最新消息”和最近五条流线。状态实现现在按事件编号排序；新断言已独立复测。
2. **预算工作阶段偏后（已修复）**。预算专家先于路线专家启动时，应进入“编排行程”。新增 budget-only 场景通过。
3. **反向 Tab 焦点未严格循环（已修复）**。总协调操作发现原生 dialog 的 Shift+Tab 可让焦点落到 body；增加显式首尾 Tab 循环后浏览器复测通过。
4. **细小状态文字偏淡（已修复）**。初版状态/任务颜色对白底约 3.16；关键小字现使用 `#667268`，对白底约 5.03。独立源码和更新截图均确认修订，未据此宣称整个应用全面满足无障碍标准。
5. **桌面出现无用的横滑提示（已修复）**。提高默认隐藏和窄屏显示规则的选择器优先级；更新桌面截图不再出现横滑提示，手机仍保留提示。
