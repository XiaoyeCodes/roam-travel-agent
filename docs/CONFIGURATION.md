## 外部服务配置

侧栏进入「模型与工具 → 申请入口」，可查看 DeepSeek、高德、Unsplash、Tavily 的申请页面、官方文档与填写步骤。每个密钥输入框旁也保留快捷链接。

| 服务     | 申请页面                                                     | 填写说明                                                               |
| -------- | ------------------------------------------------------------ | ---------------------------------------------------------------------- |
| DeepSeek | [API Keys](https://platform.deepseek.com/api_keys)           | 填入「大模型 → API Key」；其他兼容服务使用对应厂商的密钥、地址和模型名 |
| 高德     | [应用管理](https://console.amap.com/dev/key/app)             | 创建应用并添加 Key，服务平台选择「Web 服务」                           |
| Unsplash | [Your Applications](https://unsplash.com/oauth/applications) | 创建应用，复制 Access Key；图片搜索不使用 Secret Key                   |
| Tavily   | [控制台](https://app.tavily.com/)                            | 复制 API Key，填入「外部工具 → Tavily API Key」                        |

可以直接在页面侧栏「模型与工具」填写，保存后用于下一次规划。密钥字段留空表示保留原值；配置接口只返回是否已配置，不回传密钥。配置覆盖保存在 `.data/config.json`；如需清除，可以使用配置 API 的 `clearKeys` 或手动移除本地配置中的对应字段。

| 服务        | 配置                                       | 未配置时的行为                                               |
| ----------- | ------------------------------------------ | ------------------------------------------------------------ |
| 大模型      | `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY` | 真实规划提示补充配置；离线演示正常工作                       |
| 高德地图    | `AMAP_KEY`，**Web 服务类型** Key           | 不核验 POI/坐标；不伪装为高德底图                            |
| 高德交互地图 | `AMAP_JS_KEY`，**Web 端（JS API）类型**；新 Key 配套 `AMAP_JS_SECURITY_CODE` | 显示静态地图，提示配置交互地图 |
| Unsplash    | `UNSPLASH_ACCESS_KEY`                      | 南京示例逐站使用精选 Unsplash 照片；其他未覆盖地点显示待配图 |
| Tavily 搜索 | `TAVILY_API_KEY`                           | 搜索显示未配置；也可接入搜索 MCP                             |
| 天气        | 无需 Key，Open-Meteo                       | 网络失败或日期超出预报窗口时保留未知                         |
| 铁路查询    | 内置 `12306-mcp`，应用自动启动，无需 Key   | 网络失败或超出 15 天预售期时明确提示                         |
| 机票查询    | 内置 `fast-flights`，首次启动自动准备环境 | Google Flights 不可访问或解析失败时保留未知，不编造报价     |

高德 Web 服务 Key 保存后会自动尝试官方 `https://mcp.amap.com/mcp?key=...`，同时保留后端 REST 适配器。Web 服务 Key 不会放到前端地图 URL，静态地图由后端获取并以内嵌图片返回。用于 HTML 手册的静态地图服务需要具备相应权限与额度。

交互地图使用独立的网页端 JS API Key，设置中有申请入口。JS Key 与配套安全密钥以浏览器配置方式使用，会出现在网页和导出的 HTML 中；服务端模型、Web 服务和搜索密钥不会随之导出。请使用专用网页端 Key 并按使用场景设置域名白名单。导出文件联网时支持拖动、缩放、点击标记与每日地图；断网时显示内嵌静态预览。已有导出文件需要重新导出才能获得新功能。

手动从三行配置文件导入模型（依次为 Key、Base URL、模型名）

```powershell
npm run import-config -- "C:\path\to\model-config.txt"
```

### 免费铁路与机票（默认启用）

正常运行 `npm ci`、`npm run dev` 或 `npm start` 即可。12306 作为应用管理的 stdio 子进程启动，无需端口、服务地址或铁路账号；应用退出时结束。启动失败会在下次查询重试。

机票使用 `fast-flights==3.1.0`，首次启动自动在 `.data/travel-venv` 创建独立 Python 环境并安装固定版本依赖。自动寻找 uv 或 Python 3.10+；已有 uv 时可自动获取 Python 3.12。此后重启只检查依赖。Docker 已包含 Python 和 venv。初次安装需要联网；不使用收费抓取服务、不要求 API Key。若机器既没有 Python 也没有 uv，界面会给出明确提示。

进入「模型与工具 → MCP 服务」可以查看两项服务的状态，并输入城市和日期点击「实查高铁 / 实查机票」。就绪只代表组件已启动；实查结果才包含实际数据、查询时间和来源链接。也支持 `POST /api/tickets/rail/query` 与 `/api/tickets/flight/query`，请求示例 `{"origin":"上海","destination":"北京","date":"YYYY-MM-DD","passengers":1,"limit":5}`。机票可传 `maxStops: 1` 查询一次中转，默认只查直飞。

交通专家在用户确认旅行方向后，按交通偏好实际查询去程与返程；智能推荐会查询两种交通方式。铁路价格是每位成人单程价，机票是所选成人人数经济舱单程总价（CNY）。试查界面按 1 位成人查询；当前不处理儿童票价。机票人数最多 9 人，更大团队会保留待查询。

常见中文城市自动映射机场（如上海 SHA/PVG、北京 PEK/PKX），也支持准确的 IATA 三字机场代码。未收录城市不会擅自替换成邻近机场。机票取自 Google Flights 网页，可能漏供应商或受网络、页面变化影响；缺失票价保留为空，余位数量不提供。修复了上游 3.1.0 解析器漏读最佳航班分组、缺少票价时崩溃的问题。查询结果最多在内存缓存 2 分钟，保留原查询时间。

Google Flights 返回临时错误时会重试一次；验证码、访问限制或持续失败会显示查询失败。多机场查询若只成功了一部分，会在结果的 `warnings` 中列出失败的机场组合，不将缺失结果描述为没有航班。

仅在离线测试或明确不需要内置票务时设置 `ROAM_TICKETS_DISABLED=1`。查看服务状态使用 `GET /api/tickets/status`。

### 可选外部 MCP 服务

支持 Streamable HTTP 和 SSE，可配置 Bearer Token、服务名称和分配专家。设置中的「测试」会实际连接并列出允许的查询工具数。铁路社区项目示例

```powershell
npx -y 12306-mcp --port 8000
```

默认内置铁路服务不需要上述命令。仅在自行部署额外服务时，将它打印的 MCP 端点填入设置；HTTP 端点通常为 `/mcp`，旧服务可能是 `/sse`。

也可在 `.env` 中配置

```dotenv
MCP_SERVERS=[{"id":"rail","name":"12306","url":"http://127.0.0.1:8000/mcp","transport":"http","roles":["transport"]}]
```

角色可用 `attractions`、`transport`、`weather`、`hotel`、`food`、`budget`、`route`。高级配置可提供 `allowedTools` 限定具体工具名。购买、付款、删除、提交、执行命令等工具始终被排除；本应用只规划，不进行预订。

## 数据口径

总预算是**全体旅客整个行程**的预算。住宿按房间和晚数，交通按往返和人数；模型输出的分项由后端重新求和。未知金额使用 `null` 并单独计数，不能把合计当作完整价格。模型给出的费用统一标为参考估算。

地点坐标仅来自高德 POI 核验，采用 GCJ-02。模型自报坐标不会用于地图。图上折线表示游览顺序，**不是道路导航路线**。高德静态图总览受 10 个标注、4 条折线限制，界面会说明截断；每一天单独导出的地图包含当天地点。

没有高德 Key 时，演示方案显示「非高德底图」的游览顺序示意；真实方案如无核验坐标，则展示待接入说明。配置 Key 后重新生成行程即可获得坐标与高德地图；已生成的演示方案也可以在导出时取得底图。

天气只使用工具返回且覆盖指定日期的预报。超出预报窗口的日子不按历史均值冒充预报。Open-Meteo 免费接口适用于非商业用途，商业部署需评估其服务方案。

Web Search 只涵盖搜索引擎可索引内容，不保证小红书、携程的全部内容可访问。搜索摘要、POI 和模型推荐都不等于实时库存或确认价格。

Unsplash 是**真实照片搜索**，并非 AI 图片生成。结果使用 API 原图地址并显示摄影师与 Unsplash 链接。每个景点、美食停留点关联自己的照片、摄影师和原图链接。南京示例内置经过来源核对的精选照片；未能确认具体地点或餐馆的配图明确注明取景范围。配置 Access Key 后按具体景点/菜品关键词搜索，已有行程可点「补全图片」。搜索结果属于相关配图，不代表取景已由地图核验。

导出为单个 `.html` 文件，内含 CSS、章节和日期切换脚本、行程数据与每日地图。图库照片按 Unsplash 要求保留原站链接，需要联网显示；文字、预算和内嵌地图可离线查看。导出会向 Unsplash 的 `download_location` 报告 API 照片使用，不把密钥写入文件。搜索有缓存、并发和请求上限；未找到照片或请求失败时使用有来源的精选配图或明确留空。

手册采用暖米色与棕金色排版，内置行程规划、住宿交通、景点介绍、美食推荐和出行锦囊章节。HTML 对行程文字转义，并用 CSP 限定脚本和图片来源。
